About This Project

Project Overview

This educational tool predicts 10-year cardiovascular disease risk using machine learning models trained on the Framingham Heart Study dataset, one of the most important longitudinal studies in cardiovascular epidemiology.

The Framingham Heart Study began in 1948 and has followed thousands of participants over decades, collecting comprehensive data on lifestyle factors, clinical measurements, and health outcomes. This dataset has been instrumental in identifying major cardiovascular risk factors.

Dataset Information

Size & Balance
  • Total Records: 4,240 participants
  • Features: 16 clinical and demographic variables
  • Outcome: 10-year coronary heart disease (CHD) occurrence
  • Class Distribution: 84.8% without CHD, 15.2% with CHD
Key Features
  • Demographics: Age, Gender, Education
  • Lifestyle: Smoking status, cigarettes/day
  • Clinical Measurements: Cholesterol, Blood Pressure, BMI, Heart Rate, Glucose
  • Medical History: Stroke, Hypertension, Diabetes, Current BP medications

Models Used

This system uses an ensemble of 9 machine learning models for prediction:

Traditional Methods
  • Logistic Regression (Balanced)
  • Logistic Regression (Accuracy-focused)
Tree-based Ensembles
  • Random Forest (500 trees)
  • Extra Trees (600 trees)
  • Gradient Boosting
  • Histogram Gradient Boosting
Advanced Methods
  • XGBoost (400 estimators)
  • Support Vector Machine (RBF kernel)
  • Artificial Neural Network (3-layer)
Performance Metric

Models evaluated using ROC-AUC, which measures the ability to distinguish between CHD and non-CHD cases across different decision thresholds.

Primary Model Performance

Primary Model: Logistic Regression (Balanced Class Weighting)

Metric Value Interpretation
ROC-AUC 0.6975 (69.75%) Good discrimination between risk groups
Recall (Sensitivity) 0.6047 (60.5%) Identifies ~60% of actual CHD cases
Precision 0.2541 (25.4%) When predicting CHD, ~25% are true positives
Accuracy (Balanced) 0.6698 (67%) Suitable for screening rather than diagnosis

Note: This model prioritizes sensitivity (recall) over specificity, making it suitable for preliminary screening where missing risk cases is more concerning than false alarms.

Methodology & Validation

Data Preprocessing
  • Missing value imputation (median strategy for 645 missing values)
  • Feature normalization using StandardScaler
  • Categorical encoding (one-hot for education; ordinal for others)
  • Stratified train-test split (80-20)
Model Development
  • 5-fold stratified cross-validation for stability assessment
  • Class imbalance handling via class weights (5.6:1 ratio)
  • Model comparison using ROC-AUC as primary metric
Evaluation
  • Test set performance: 848 unseen samples
  • Confusion matrices and ROC curves generated
  • All models evaluated consistently on same test set
